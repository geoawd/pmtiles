Use the Legend to switch layers on and off and adjust their transparency.

Use Search to find features in the current map view e.g. searching in an attribute table.

Use the box tool to select features by dragging a rectangle on the map.

An unofficial, experimental map viewer for Geological Survey of Northern Ireland datasets. Data is derived from Open Data or consumed via OGL services.

Data is derived from data available under the OGLV3.
